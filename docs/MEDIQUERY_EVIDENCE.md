## Portfolio Retrieval Explorer

Public fixtures: five fictional document labels and two-dimensional vectors, query `[1,0]`. No paper findings, clinical facts or real BioBERT coordinates. Diagram plots unit directions solely to explain cosine selection; adjacent HTML table and ordered summary remain accessible.

`src/lib/retrieval.ts` calculates cosine similarity and real greedy MMR. First seed is the most query-similar document. Each later selection maximises `λ × query_similarity − (1 − λ) × greatest_similarity_to_selected`; exact ties preserve fixture order. k=3. Similarity-only gives A/B/C; λ=.5 gives A/D/B; λ=0 gives A/E/D; λ=1 returns A/B/C. The zero-weight example deliberately shows that diversity can select a query-orthogonal document. Scores are not probabilities, evidence quality or model evaluation.

Math tests cover direction/orthogonality/opposition, invalid/zero vectors, deterministic output, ties, weighting bounds, zero/oversized k, invalid k, score arithmetic and fixture immutability. Browser tests cover method selection, keyboard/touch, range boundaries, accessible HTML and no-JavaScript computed summary. This is not an execution of MediQuery's Python retrieval pipeline or a full ingestion-to-answer replay.
