## Architecture and source boundaries

[Model contract and confidentiality record](LAB_COLLECTION_MODELS.md) gives exact transitions, assumptions, source distinctions and limits. Public fixtures, pure functions, state, playback, presentation and internal evidence remain separate.

- Shared Server Component frame: metadata, breadcrumb, boundary, concise lesson, no-JavaScript representative example, case-study/experiment navigation. It does not dictate each workspace's layout or state machine.
- AutoMark: separate copied terminal summaries and comparison qualification; existing scheduler unchanged. Retention is in mounted memory, survives reset and can be cleared. Leaving the route discards it. Current activity uses actual model events.
- EquityGuard: pure guarded event reducer and one cleaned-up viewing timer. Required ticker and public payload names follow the pinned source. FICT, selections, data and response are authored fixtures. Error-dictionary stopping is explicitly an educational extension, not original guaranteed recovery. Checks cover public field shapes, not private traces or financial correctness.
- MediQuery: original tested cosine/MMR functions reused. Stable source/chunk IDs drive selection, context and prepared statements. Authored highlighting is not original automatic citation verification; no generation/embedding/provider runs.
- Returns: explicit branching reducer around the existing fictional policy. Trusted fictional order data stays separate from prepared interpretation. Missing/invalid information stops before policy; details/corrected fixtures resume through explicit actions. No original assessment policy, customer record or private trace.
- DAITA: existing parsers/normalisation/duplicate checks reused with four new records. Immutable originals, separate edit map, deterministic quality/disposition/review derivation, conservation of every row and reviewed-only CSV text. No tax rules, ATO references, confidence scores, real uploads or original client material.

Internal evidence never becomes a client import. Entry links disable prefetch; loaded-script checks cover homepage/Lab visits and hover. No backend, database, authentication, model/API key, live service or large animation dependency. New route metadata, canonical URLs, WebApplication structured data, sitemap and four original 1200×630 social PNGs are included.

External-project tests remain separate historical evidence at their documented scope. They were not rerun or claimed as new integration verification. No new professional metric or original-runtime claim was introduced.

## Candid visual and engineering assessment

The strongest result is that the five interactions now teach different ideas through actual state and transformations. AutoMark preserves the scheduling sheet; EquityGuard exposes observable events; MediQuery retains reference identity; Returns makes clarification and policy separate; DAITA keeps source and review together. The opening index makes this a collection visitors can choose from immediately.

Mobile remains deliberately sequential, particularly the source/review and evidence workspaces. Compact registers, in-context continuation and bounded/stable controls improve access, but physical-device and screen-reader usability sessions should guide a future focused-record/source view. More visual polish should follow those observations rather than adding activity or length. Cross-browser verification remains worthwhile.

The models are bounded and deterministic. They do not establish live agent, retrieval, citation, workflow, document-processing or original cloud reliability. Prepared fixtures and education-specific guards are explicit. New historical source/runtime evidence, original project evaluations and permission-cleared product materials would improve technical credibility further; those gaps are preserved in the original inventories. Further Lab refinements should stay distinct and scoped. No unrelated feature phase has begun.
